# World News — Thursday 19 November 2026

One image summing up the world's news of **Thursday 19 November 2026**, built for make.fun's `news-image-20261119` bounty.

## The image

`entry.png` (1024×1024) is drawn programmatically with Python and PIL — see `draw.py`. No AI image generator was used, so every word on it is typeset and nothing is garbled. `main.ts` copies it to `/output/entry.png`.
